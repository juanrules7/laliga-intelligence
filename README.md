# La Liga Intelligence

Eight seasons of La Liga data, xG, squad value, and manager skill, distilled into one place.

This dashboard is the companion tool for an ongoing article series on separating luck from
skill in football results. It's being released alongside the series, one article at a time —
right now it covers **Article 1 — The Framework**: xG, xPts, the squad-value budget model, and
Manager Skill. More tabs unlock here as each subsequent article is published.

## Run locally

```
pip install -r requirements.txt
streamlit run dashboard_public.py
```
